# XML-Riivolution-Maker
A CLI tool for creating an XML file for Riivolution

**Currently works only for SMG 1**
**and is still in the beta stage!**

**How ​​it works**

Launch the file "XML Riivolution Maker.exe".

Then select the target folder (although the program prompts you to select the original game's folder, this does not work; the XML file is created in the same folder as the .exe file!).

Next, select the mod folder (the folder containing your modified files, e.g., the "StageData" folder).

Then select the version: PAL, NTSC-U, or NTSC-J (**Do not delete the "game_versions" folder under any circumstances!**).

After that, you will be asked if you are using custom code. Select "y" or "n"; it does not matter, as this feature is not (yet) implemented.

Finally, choose a name.

You have now created an XML file for Riivolution (please note that this is a beta version; the XML file may not work).

# Créateur de fichiers XML Riivolution

Un outil en ligne de commande pour créer un fichier XML pour Riivolution

**Fonctionne actuellement uniquement avec SMG 1**

**Encore en version bêta !**

**Fonctionnement**

Exécutez le fichier « XML Riivolution Maker.exe ».

Sélectionnez ensuite le dossier cible (le programme vous propose de choisir le dossier du jeu original, mais cela ne fonctionnera pas ; le fichier XML sera créé dans le même dossier que le fichier .exe !).

Sélectionnez ensuite le dossier du mod (le dossier où vous avez modifié les fichiers, par exemple le dossier « StageData »).

Sélectionnez ensuite la version : PAL, NTSC-U ou NTSC-J (**Ne supprimez en aucun cas le dossier « game_versions » !**).

Vous serez ensuite invité à indiquer si vous utilisez du code personnalisé. Sélectionnez « o » ou « n » ; cela n’a pas d’importance, car cette fonctionnalité n’est pas encore implémentée.

Enfin, choisissez un nom.

Vous avez maintenant créé un fichier XML pour Riivolution (notez qu'il s'agit d'une version bêta ; le fichier XML peut ne pas fonctionner).
